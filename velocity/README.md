# Velocity plugin

Velocity proxy plugin that authorizes backend-authenticated players joining the
network. It validates the player's identity against the Go backend before
allowing the connection.

## Build

Requires a JDK (tested with Temurin 21). The Gradle wrapper self-downloads
Gradle 9.2.1 on first use.

```bash
# Windows
gradlew.bat build

# Linux / macOS
./gradlew build
```

The built plugin jar is written to `build/libs/`.

## Layout

- `src/main/java/net/minecraftserverlauncher/velocity/` — plugin sources.
- `build.gradle.kts` — build configuration (Velocity API 4.2.0, Java 17 target).
- `gradle/wrapper/` — Gradle wrapper (generated by `gradle wrapper`).

## Security

The proxy is an enforcement point, never the source of truth: it asks the
backend to validate an identity claim and rejects joins the backend does not
authorize. See `docs/DECISIONS.md` (server-side authorization is authoritative).
